# proyecto_sprint_7
Este conjunto de código aborda el desarrollo del proyecto del sprint 7 y tiene como objetivo practicar tareas habituales de la ingeniería de software como:
1. Creación y gestión de entornos virtuales de Python
2. Desarrollo de una aplicación web.

Para cumplir los objetivos se utilizará el conjunto de datos de anuncios de ventas de vehículos usados en Estados Unidos.

En este sentido, la aplicación web desarrollada permite la visualización del comportamiento de las ventas mediante un histograma y un gráfico de dispersión, seleccionables a través de casillas de verificación (checkboxes).
